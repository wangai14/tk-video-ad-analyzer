你说的是已经开源到 GitHub 的 tk-video-ad-analyzer skill。它的定位不是“单纯翻译文案”，而是一个 TikTok 广告素材分析 + 本地化文案生成工作流：
GitHub 仓库
本地目录：C:\Users\Administrator\.qclaw\skills\tk-video-ad-analyzer
核心作用
1. 分析视频素材
   - 用 ffmpeg 抽关键帧
   - 支持场景变化检测和时间均匀采样
   - 提取视频时长、分辨率、帧率、音轨等元数据
   - 提取音频，方便后续做语音转写
2. 生成结构化分析笔记
   - 整理产品名、品类、前 3 秒钩子、卖点、证明、优惠、CTA
   - 记录旁白、字幕、画面文字语言
   - 记录模特地区、BGM、货币、是否需要重剪
   - 支持视频原文、字幕、旁白转成 TikTok 正文
3. 抓取和校验落地页
   - 提取页面标题、商品名、价格、优惠、CTA、保障信息
   - 支持静态页面，也支持可选 Playwright 渲染 JS 页面
   - 做视频卖点和落地页的一致性校验
   - 标记哪些价格、折扣、功能不能写进广告，避免编造
4. 给素材打分
   - 8 个维度：钩子强度、卖点清晰度、证明可信度、优惠驱动力、CTA、节奏、互动驱动、合规性
   - 输出总分、可信度、投放判断
   - 判断是“可直接投放”“需本地化”还是“不建议投放”
5. 生成多市场文案
   - 当前内置市场：日本 jp、泰国 th、印尼 id
   - 日本市场支持：
     - 反差型标题
     - 功能揭秘型标题
     - 痛点型标题
     - 损失厌恶型标题
     - 紧迫感型标题
     - 价格刺激型标题
   - 每条标题可自动追加 2-3 个 #关键词
   - 支持生成 100 字以内的日语 TikTok 正文
   - 支持 CTA、贴片字幕、Hook 方案
6. 标题评分和优化
   - 按停顿感、好奇心、痛点命中、转化相关、合规安全评分
   - 输出 Top 5 推荐标题
   - 可以接入历史 CTR / CVR / ROAS / CPA 数据，校准标题角度
   - 自动降低说明书式、商品名开头、过长标题、强风险词标题的分数
7. 输出剪辑建议
   - 15 秒强转化版时间线
   - 25 秒解释版时间线
   - 前 3 秒优化建议
   - 封面建议
   - A/B 测试矩阵
8. 批量分析
   - 可以递归扫描多个 extraction_result.json
   - 批量生成报告
   - 输出 CSV 汇总，适合做素材库排行
9. 合规和风险控制
   - 不编造价格、折扣、销量、功效、材质、认证
   - 日本美妆规则会规避 絶対、必ず、100%、治る、改善 等高风险表达
   - 对视频里出现的医疗、认证、销量类说法会先做风险过滤
它实际解决的工作
你可以把一个视频、产品名、落地页、目标市场交给它，然后得到：
- 素材能不能投
- 前 3 秒钩子行不行
- 卖点展示够不够
- 视频和落地页是否一致
- 20 条广告标题
- Top 5 标题
- 前 3 秒 Hook 方案
- 100 字以内主文案
- 贴片字幕
- CTA
- 15 秒和 25 秒剪辑建议
- report.md 和 report.json
当前限制
- 它不是端到端的视觉大模型，不能只靠脚本自己理解所有画面；核心依赖抽帧后由 AI 阅读，或者填写 notes.json
- 当前内置市场只有 jp / th / id，没有完整的内置韩语市场引擎
- 韩语文案目前更多依赖 AI 在对话中临时生成，不是这个仓库脚本的本地化模块
- 落地页校验主要是文本匹配，不是语义级严格核对
- 强 JS 页面需要额外安装 Playwright
- 不同品类中，日本时尚和美妆规则最完整；普通品类会走通用文案模板
一句话：它是给 TikTok 素材做“诊断、评分、本地化改写、标题优化、落地页校验、剪辑建议和批量报告”的工具，不是单纯的翻译器，也不是 TikTok 广告后台投放系统。
